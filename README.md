# 天翼智屏 ZXV10 S100V8H · VH8助手

## 软件介绍

**VH8助手**是为天翼智屏 ZXV10 S100V8H 制作的本机维护与配置工具。它把原先需要通过 ADB、手动安装 APK、逐项配置系统入口的流程，整理为设备上的触屏操作，便于恢复和管理常用功能。它面向 Android 9、API 28，并且只对已经核验的型号和固件指纹开放写入操作。

VH8助手通过设备固件内已有的厂商特权命令服务执行受限的固定配置任务。它不是通用 Root 工具，也不安装 Magisk；Root 状态指的是本机命令通道能够以 UID 0 执行。应用不解锁 bootloader、不刷写系统分区、不清除用户数据。运行前会尝试备份关键配置和 APK，操作结果与恢复入口可在应用中查看。

## 功能总览

- **一键完整配置**：按顺序检查设备兼容性与 Root 通道、备份配置和关键 APK、安装内置 Aerial、修复公共 U 盘挂载、启用 Aerial 主页接管与 ADB 开机恢复，并拦截已识别的 OTA 更新入口。
- **Root 入口**：验证 UID 0 能力并建立仅供本机 ADB shell 使用的命令入口。不会向其他 App 自动授予 Root。
- **Aerial 桌面**：内置 Aerial 安装包；启用后将主页入口转给 Aerial，同时保留原厂桌面和安装包，以便回退。
- **USB U 盘修复**：检查系统识别到的公共存储卷，尝试挂载处于未挂载状态的 U 盘，并在新卷接入时打开用户选择的文件管理器。不会格式化 U 盘或安装文件管理器；请先自行安装文件管理器。
- **ADB 调试恢复**：开启 USB／网络调试设置并保存开机恢复偏好。网络 ADB 默认使用 5555 端口，只应在可信局域网使用。
- **电源键息屏与唤醒**：独立测试顶部电源键短按熄屏、再次短按唤醒；通过实机测试后才保存接管。长按关机菜单、音量键和禁麦键保留原行为。默认沿用设备已有的 07:00–23:00 时间表；此工具不包含持仓屏保。
- **系统更新拦截**：保存更新设置并拦截已识别的厂商升级服务、广播和页面；可以撤销 VH8 自己添加的规则。此功能只覆盖已分析的入口，不保证阻止所有厂商升级路径。
- **状态与恢复**：显示各功能启用情况；“更多”里查看操作历史、备份位置，并停止桌面接管、USB 自动打开、ADB 开机恢复或电源键管理。

## 使用方法

1. 安装仓库中的 `VH8助手-v24.apk` 并打开。
2. 在首页点击 **一键完整配置**，阅读确认提示并等待每个阶段完成。失败时先查看“更多 → 操作记录”，不要重复提交仍在运行的任务。
3. 确认 Aerial 已安装并成为主页后，测试 USB 插入行为和 ADB 恢复状态。
4. 如果要使用电源键息屏，单独打开电源键卡片，按提示短按测试熄屏，再按一次测试唤醒；测试通过后再启用。
5. 通过“更多”查看本机备份位置与操作记录。备份不包含完整系统固件、所有应用私有数据或账号数据；请将重要备份另行复制保存。

## 源码构建

源码 ZIP 包含 Android 界面与服务、Root 固定任务、Aerial 离线安装包、电源控制组件和所需运行资源。构建依赖 JDK、Android 28 SDK/aapt2、D8/R8、Python，以及本机配置的签名密钥。仓库不包含签名私钥；构建脚本里的 JDK、SDK、R8 和签名密钥路径需按自己的电脑调整。自行构建的 APK 若使用不同签名，可能无法覆盖更新设备上已有版本。

## 兼容性、验证与限制

仅针对 `ZXV10 S100V8H` 和固件指纹 `ZTE/rk356x_box_32/rk356x_box_32:9/PI/20260817:user/release-keys` 开放写操作。其他设备或固件只应进行只读检查，不能假设相同配置适用。

当前设备上已验证厂商 Root 通道 UID 0、Aerial 主页接管、ADB 恢复、USB 自动入口、电源键短按熄屏与唤醒。VH8 v24 在全新出厂设备上的首次完整配置与完整重启恢复尚未端到端验收。OTA 规则只针对已确认组件；无完整系统分区备份和独立救援链路时，不应执行刷机、解锁或清数据操作。
